`twojstar/twojstar` is the shared workshop for small tools that are easier to maintain together than as a swarm of tiny repositories.

## One rolling release

The repository publishes one moving **Latest** release. Individual project workflows build and attest their artifacts; the central publisher assembles successful product bundles and updates the shared release.

<Card title="Download Latest" icon="download" href="https://github.com/twojstar/twojstar/releases/latest">
  Current workshop bundles and checksums.
</Card>

## Maintenance model

- Dependabot covers the mixed stacks individually.
- CodeQL uses GitHub default setup.
- CI is path-filtered so unrelated projects do not rebuild unnecessarily.
- Cloudflare-backed projects read from the repository's `main` branch.
