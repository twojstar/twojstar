## How the pipeline works

```text
feeds.yaml
   ↓
fetch → parse → normalize → enrich → deduplicate
   ↓
feeds/*.xml + *.json
   ↓
GitHub Pages + reader
```

Feedseek prefers reliable native RSS/Atom when available, but treats it as upstream material rather than sacred final output. Useful metadata can be repaired or enriched when the source gives enough evidence.
