LlmBench supports multiple AI providers through two layers: account-backed WebViews for services you sign into, and a planned native layer for free API-compatible endpoints. This page documents which providers are supported, which work fully or partially, and how LlmBench adapts provider pages for mobile use.

<Warning>
  Some providers may block embedded login or restrict WebView access. LlmBench does not scrape passwords, session cookies, or OAuth tokens. Authentication remains strictly between the embedded provider page and that provider.
</Warning>

## Native/free-provider layer (planned)

LlmBench is building adapters for free API-compatible providers so you can chat and compare without separate web accounts:

- **OpenRouter-compatible services**
- **AIHubMix** (where terms and APIs allow)

Provider-specific implementation details stay behind adapter interfaces rather than being scattered through the UI code.

## Provider tweaks and mobile layout

Provider web pages are designed for desktop browsers. LlmBench adapts them for mobile through a small, auditable userscript and CSS adapter layer that:

- Fixes mobile layout issues
- Reduces unnecessary chrome and animations
- Handles provider-specific navigation quirks

<Note>
  These tweaks are currently internal, but LlmBench plans to expose a provider-tweak/userscript interface so customizations can be maintained outside the core app code.
</Note>
